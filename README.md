# Flixplore 🎬

An online **movie streaming platform** with a **recommendation chatbot** that helps users find movies tailored to their preferences.  
This platform allows users to browse, watch, and get movie suggestions using the AI-powered chatbot.

---

## 🌟 Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Authentication & Security:** JWT  

---

## ⚡ Features

- User **Authentication** & **Authorization**  
- Multi-role support: **Audience**, **Admin**  
- Movie streaming & browsing  
- AI-powered **Recommendation Chatbot** to filter movies based on audience preferences  

---

## 👥 User Roles

| Role       | Access & Permissions |
|------------|-------------------|
| Audience   | Browse movies, watch, use chatbot for recommendations |
| Admin      | Manage movies, users, and platform content |

## 💻 Setup Instructions

1. **Clone the repository** and move to the parent `Flixplore` folder:

2. **Backend**
- cd backend
- npm install
- npm run dev

3. **Frontend**
 - cd frontend
 - npm install
 - npm run dev
